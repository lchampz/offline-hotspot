# ServidorEmergencia

Phoenix app for the [Emergency Network](../README.md) — notice board,
real-time chat, and offline documents. See the repository's main README
for the full project context.

```bash
mix setup
mix phx.server
```

Visit [`localhost:4000`](http://localhost:4000).
